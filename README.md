# VM Lifecycle Project

Проект посвящён исследованию жизненного цикла виртуальных машин и прогнозированию потребления вычислительных ресурсов в облачных инфраструктурах. Основной фокус работы — анализ временных рядов загрузки CPU и RAM, предварительная обработка больших трассировочных датасетов, построение признаков и подготовка данных для последующего машинного обучения.

В проекте используются два открытых источника данных:

- **Azure Public Dataset V2 (2019)** — данные о виртуальных машинах Microsoft Azure;
- **Google Cluster Data 2019** — трассировочные данные Google Borg, в частности кластер `A`.

Репозиторий содержит материалы по загрузке, обработке, описанию структуры данных, EDA и подготовке итоговых выборок для моделирования.
